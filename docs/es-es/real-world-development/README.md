Explora GitHub Copilot durante el ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y una lista de trabajo compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que financia proyectos de juegos de mesa y tiene una temática de desarrollo. La lista de trabajo de tu equipo ya está disponible como incidencias de GitHub. Incluye tareas de funcionalidades, como el filtrado y la paginación, y mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elegir el entorno

GitHub Copilot te acompaña en el entorno que elijas. Selecciona el que mejor se adapte a tu forma de trabajar. Cada taller empieza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Utiliza el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, MCP de Playwright, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia entre modos de sesión, colabora con lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Utiliza GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
